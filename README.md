# 漢字 N4 Flashcards

A flashcard web app for studying the first 40 N4 kanji, built so each word is drilled in context rather than in isolation.

**Live app:** https://hafizulrifkihawari.github.io/jp-flashcard/

## What it does

- **400-card deck** — 40 kanji × 10 cards each: 1 card for the word alone, plus 9 cards using it inside a short sentence.
- **Conjugation drills** — for the 18 verbs/adjectives, the 9 sentence cards cycle through real grammatical forms (dictionary, -masu, -te, -ta, -nai, -mashita, -masen, -nakatta, potential), generated by a tested conjugation engine so the Japanese is always correct.
- **Varied sentences for nouns** — the 22 nouns instead get 9 different hand-written usage sentences (different particles/contexts) since they don't conjugate.
- **Romaji** (toggleable) — a hiragana-to-romaji converter that correctly distinguishes grammar particles (は/へ/を → wa/e/o) from words that merely start with the same kana.
- **Text-to-speech** (toggleable) — reads the card aloud via the Web Speech API, preferring a Japanese "Mizuki" voice with graceful fallbacks if it isn't installed on your device.
- **Cloze mode** — blanks out the target word in its sentence for stronger recall.
- **Installable PWA** — works offline once installed; add it to your phone's home screen via the browser's "Install app" / "Add to Home Screen" option.
- Shuffled by default, with filters for verbs / adjectives / nouns, and keyboard shortcuts (Space to flip, ←/→ to navigate, S to shuffle, P to play audio).

## Running locally

No build step — it's plain HTML/CSS/JS. Either open `index.html` directly, or serve it:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.

## Files

| File | Purpose |
|---|---|
| `index.html` / `styles.css` | App structure & UI |
| `app.js` | Card rendering, navigation, TTS, romaji toggle |
| `data.js` | The 40-kanji dataset, flattened into the 400-card deck |
| `conjugate.js` | Verb/adjective conjugation engine |
| `romaji.js` | Hiragana → romaji converter |
| `manifest.json` / `sw.js` | PWA install & offline support |
